# 筋トレ栄養管理(個人用PWA)

筋トレをする本人専用の栄養・体組成管理アプリ。データは端末内(IndexedDB)にのみ保存されます。
仕様: `claude-prompt-v2.md` / 現在の実装段階: **段階4(全段階実装済み)**

## 使い方
1. 公開URLをiPhoneのSafariで開き、**ホーム画面に追加してから**初期設定を行う
   (Safariのタブとホーム画面アプリは保存領域が別のため)。
2. 初期設定で プロフィール・目標・活動量を入力 → 目標カロリーとPFCが自動計算されます。
3. 「食事」タブで 手入力 / マイ食品 / 履歴コピー で記録。ホームの体重欄でクイック体重入力。
4. 「設定」タブから **14日ごと**にバックアップ(JSON)を書き出し、iCloud Drive 等へ保存してください。

## 開発
```
npm install
npm run dev      # 開発サーバー
npm test         # Vitest(計算・週平均・バックアップ復元)
npm run build    # dist/ に静的ファイルを出力
npm run icons    # アイコン再生成
```

## 静的ホスティング(無料枠)
`dist/` を GitHub Pages / Cloudflare Pages / Netlify 等の無料枠に置くだけです(`base: './'` のためサブパスでも動作)。
サーバーサイド処理はありません。有料プランは不要です。

## データと保存
- 記録は端末内のみ。外部へ送信しません(段階2以降のGemini解析リクエストを除く)。
- 写真は保存しません(段階2以降。画像用の保存先はコード上に存在しません)。
- Service Worker のキャッシュはアプリ本体(HTML/JS/CSS/アイコン)のみです。

## AI機能(Gemini無料枠)の注意
- AIは Google Gemini API の**無料枠のみ**。APIキーは**課金(Billing)を有効化していない Google Cloud プロジェクト**で発行すること。
  請求アカウントを紐づけて課金を有効化すると、無料枠を超えた分が課金される可能性があるので有効化しないこと。
- 無料枠では、送信した写真・文章が Google の製品改善等に利用される場合があります。体組成シートは氏名・会員番号が写らないよう撮影してください。
- 無料枠の上限とモデル名は Google AI Studio で確認し、設定画面で変更します(既定モデル `gemini-3.8-flash`、1日の上限は `DAILY_AI_LIMIT`=20回)。
- APIキー・モデル上書き・同意は端末の localStorage にのみ保存され、バックアップJSONには含まれません。
